# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive sales analysis
dashboard for Blinkit using Microsoft Power BI.

## Key Performance Indicators
- Total Sales
- Average Sales
- Number of Items
- Average Rating

## Dashboard Features
- Sales Analysis
- Fat Content Analysis
- Item Type Analysis
- Outlet Size Analysis
- Outlet Location Analysis
- Outlet Establishment Trends
